# Sniper Scalper App — UI Kit

High-fidelity recreation of the Android app (412×917), reconstructed from the 6 provided screenshots (no codebase/Figma available). Click-through: bottom nav switches screens; Academy course → course detail.

Screens: Splash, Academy (course list), Course Detail (SMC), News feed, Settings.
Omitted: Home and the live TradingView chart screen — the chart is an embedded third-party TradingView widget, not app UI; recreating it would be misleading. A placeholder note marks it.

Composes `components/` primitives via the compiled bundle. Imagery cropped from the real screenshots (`assets/`).
